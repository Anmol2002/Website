01Overview

A dark, cinematic sneaker launch site animated frame by frame in Figma.

Halcyon HX-01 is a concept sneaker launch site. I designed and animated twelve key frames in Figma: a loader, three colourways, three angle views, tech hotspots, the product page and the bag drawer, plus a design system covering type, colour, colourways, components and motion.

02The challenge

What had to be solved

Product launch sites need to feel premium and cinematic, but they still have to sell. Motion can easily become decoration that slows people down.

Design goals

  1. Make the product the hero of every frame
  2. Use motion to explain, not decorate
  3. Get from intro to add to bag smoothly
  4. Document motion so it can be built

03Process

How I approached it

  1. StoryboardTwelve frames planned as a sequence: load, reveal, colourways, angles, tech, buy.
  2. Colour as moodEach colourway changes the background glow to match the shoe.
  3. Smart AnimateFrames connected in Figma so layers glide between states.
  4. System and specsTypography, colour, components and easing curves documented.

08Product page and bag

Size selection and a slide-in bag drawer complete the journey.

09Design system

Motion that can be built.

Type, colour, colourways, components and easing curves documented for development.

10Decisions

Key design decisions

Glow follows the colourway

The background light shifts with each colourway, making the switch feel physical.

Motion with purpose

Every animation either reveals the product or moves the user closer to buying.

Documented easing

Expo and soft curves are specified so developers can match the Figma motion.

11Design system

Visual language

Near-black backgrounds with warm product light, an orange accent for actions, and minimal type so the shoe dominates.

Ember#F08A3C
Ink#0E0D0C
Graphite#2A2826
Ice#BFD9F2

TypeHanken Grotesk, Geist and Geist Mono

12Outcome

What was delivered

Halcyon is a cinematic launch concept where twelve animated frames tell a product story from first glance to add to bag, with a system ready for development.

If the project continues, next I would:

  • Build it with GSAP and WebGL
  • Add a 3D viewer
  • Create a mobile-first version
